# QR Attendance

A mobile QR attendance application built with Expo SDK 57 and React Native. It supports event QR creation, camera-based attendance scanning, local attendance history, and student profile information.

## Requirements

- Node.js 22.13 or newer
- Current Expo Go with SDK 57 support

## Setup

```powershell
npm install --legacy-peer-deps
npx expo start
```

Scan the terminal QR code using Expo Go. You can also press `w` to run the web version.

## Validation

```powershell
npx tsc --noEmit
npx expo-doctor
```
